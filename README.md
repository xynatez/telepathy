# Telepathy Lab.

Website siap dibuka dengan `index.html`. Semua foto, font, dokumen, CSS, dan JavaScript ada di dalam paket ini.

Untuk hosting, unggah seluruh isi paket ke direktori publik pada layanan hosting statis. Pertahankan struktur folder dan huruf besar pada nama file. Website tidak membutuhkan backend atau proses build tambahan.

Source yang bisa diedit:

- `index.html`: isi halaman dan formulir.
- `css/style.css`: layout, warna, tipografi, dan animasi.
- `js/script.js`: data 19 foto dan seluruh interaksi.
- `assets/documents`: tiga dokumen dari website asal.
- `assets/fonts`: font lokal beserta lisensinya.

Formulir menyusun brief dan menampilkan pesan untuk diperiksa. Tombol lanjutan membuka WhatsApp dengan pesan tersebut; pengguna mengirimkannya sendiri di WhatsApp. Nomor kontak menggunakan data dari website asal.

Animasi menghormati preferensi reduced motion. Galeri memiliki filter dan penampil foto dengan kontrol keyboard. Di ponsel, navigasi tersedia melalui tombol Menu.
